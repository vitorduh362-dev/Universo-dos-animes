 Projeto Web: Universo dos Animes

 Descrição Breve
Sistema web desenvolvido como parte da avaliação de Progressão Parcial da disciplina de Internet e Aplicações WEB do curso técnico em Desenvolvimento de Sistemas do Instituto Federal do Piauí (IFPI). O projeto aborda a temática de animes clássicos, implementando um layout responsivo, páginas interconectadas, tabelas analíticas e formulários interativos.

 Tecnologias Usadas
 HTML5 (Estruturação semântica de páginas web)
 CSS3 (Estilização personalizada, tipografia e efeitos visuais)
Bootstrap 5 (Framework para design responsivo e grid system de colunas)
Git e GitHub (Controle de versão e hospedagem do repositório)
